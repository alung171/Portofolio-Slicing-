# Portfolio Fahrul

Website portfolio pribadi yang dibuat untuk memperkenalkan diri, menampilkan skill, project, dan informasi kontak. Website ini dibuat menggunakan **HTML, CSS, dan JavaScript**.

## Tentang Project

Website ini merupakan portfolio sederhana milik Fahrul yang dibuat sebagai media untuk belajar dan menerapkan dasar-dasar pengembangan website.

Website memiliki beberapa bagian utama:

* **Home** — Menampilkan nama, profesi, deskripsi singkat, dan tautan sosial media.
* **About** — Berisi informasi singkat mengenai diri dan tujuan belajar.
* **Skill** — Menampilkan kemampuan dalam HTML, CSS, dan JavaScript.
* **Project** — Menampilkan beberapa contoh project website.
* **Kontak** — Menampilkan informasi untuk menghubungi pemilik portfolio.

## Teknologi yang Digunakan

* **HTML5** — Membuat struktur halaman website.
* **CSS3** — Mengatur tampilan, layout, warna, responsive design, dan mode terang.
* **JavaScript** — Menambahkan fitur interaktif pada website.

## Fitur

### 1. Responsive Design

Website dapat menyesuaikan tampilan pada:

* Desktop
* Tablet
* Smartphone

CSS menggunakan media query untuk mengatur layout pada ukuran layar yang berbeda.

### 2. Dark Mode & Light Mode

Tersedia tombol untuk mengganti tema website antara mode gelap dan mode terang. Fitur ini menggunakan JavaScript dengan class `terang`.

### 3. Responsive Mobile Menu

Pada perangkat dengan layar kecil, menu navigasi dapat dibuka dan ditutup menggunakan tombol hamburger.

### 4. Smooth Scroll

Navigasi antarbagian website menggunakan smooth scrolling sehingga perpindahan halaman terasa lebih halus.

### 5. Tombol Kembali ke Atas

Tombol kembali ke atas akan muncul ketika pengguna melakukan scroll lebih dari 400px. Ketika diklik, halaman akan kembali ke bagian atas dengan animasi smooth scroll.

### Penjelasan File

**`index.html`**
Berisi struktur utama website seperti navbar, Home, About, Skill, Project, Kontak, dan Footer.

**`style.css`**
Berisi seluruh styling website, termasuk layout, warna, card, responsive design, dan mode terang.

**`script.js`**
Berisi fungsi interaktif seperti mobile menu, pergantian tema, dan tombol kembali ke atas.

**File gambar**
Digunakan sebagai foto profil pada bagian Home.

## Cara Menjalankan

1. Download atau clone repository ini.
2. Pastikan semua file berada dalam satu folder.
3. Pastikan file gambar berada pada folder yang sesuai.
4. Buka file `index.html` menggunakan browser.

Atau jika menggunakan **Visual Studio Code**, project dapat dijalankan menggunakan extension **Live Server**.
